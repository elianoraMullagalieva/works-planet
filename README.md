# Планета работ

Самостоятельный блок портфолио: 3D-планета из первых экранов сайтов и карточек-заглушек про заявки.
Распределение Фибоначчи по сфере, CSS 3D без WebGL. Крутится сама и от перетаскивания, плитки под заголовком тают.

```bash
npm i
npm run dev     # http://localhost:5182/works-planet/
npm run build   # dist/
```

Механика — `src/sphere.ts`, набор плиток — `src/main.ts` (массив `SEQ`), картинки — `public/works/`.
